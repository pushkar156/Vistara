# Vistara 🧭 — Implementation Phases & Roadmap

This directory contains the detailed engineering plans for transforming **Vistara** into the AI-Powered Career Path Simulator (Class 10 to Career) for **Hackmatrix 5.0 (Track MISC — 01)**.

---

## 🗺️ Master Phase Overview

| Phase | Phase Name | Focus Area | Deliverables | Status |
|:---:|---|---|---|:---:|
| **01** | [Student & Parent Profile Intake](./phase-1-profile-intake.md) | Class 10 Onboarding & Inputs | Class 10 marks, aptitude test, budget brackets, country preferences | ⏳ Ready |
| **02** | [AI Multi-Pathway Simulation Engine](./phase-2-ai-pathway-simulation.md) | Genkit Flows & Core Schemas | 3–4 end-to-end academic pathways (11/12 stream $\rightarrow$ exams $\rightarrow$ degrees $\rightarrow$ careers) | ⏳ Ready |
| **03** | [Institution Comparator & Scholarships](./phase-3-institution-comparison-scholarships.md) | Global Institutions & Funding | Cross-country college comparisons (tuition, duration, admissions) + relevant scholarships | ⏳ Ready |
| **04** | [Financial & Loan Cost Simulator](./phase-4-financial-loan-simulator.md) | Loan Modeling & ROI | EMI, Moratorium, Total Interest, and "Relative Cost of Borrowing" debt-to-income analysis | ⏳ Ready |
| **05** | ["What-If" Engine & Decision Matrix](./phase-5-what-if-engine-decision-matrix.md) | Contingency & Tradeoff Analysis | Interactive pivots ("No MBBS", "Budget cut 50%"), Decision Matrix radar, Uncertainty index | ⏳ Ready |
| **06** | [UI/UX Visual Refinement](./phase-6-ui-ux-refinement.md) | Premium Polish & WOW Factor | Glassmorphic visual system, Framer Motion transitions, responsive charts, interactive trees | ⏳ Ready |
| **07** | [Testing & Deployment](./phase-7-testing-and-deployment.md) | Validation & Production Release | Unit & integration tests, edge cases, Firebase rules audit, deployment configuration | ⏳ Ready |
